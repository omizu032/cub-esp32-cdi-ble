# 開発コンテキスト：スーパーカブ90 デジタルCDI 最適化プロジェクト

本ドキュメントは、「ハードウェア・ソフトウェアの最適化開発制御エンジニア」および「内燃機関のプロフェッショナル」としてデジタルCDI開発プロジェクトを進めるための、前提条件、要求仕様、デバッグ履歴を集約したものです。

---

## 1. プロジェクト基本前提（Project Prerequisites）

* **対象車両**: ホンダ・スーパーカブ90（HA02型 / 98ccボアアップ / KEIHIN PE24キャブレター換装）
* **車体電源**: DC全波整流化済み（ジョルノクレア純正レギュレータ換装）、極めて安定した **DC12V（アクセサリー電源）** ラインを確立。
* **点火方式**: **AC-CDI方式** を維持（エキサイタコイルの交流数百Vを点火エネルギーとする）。CDI内部のサイリスタが点火トリガーによって導通し、点火コンデンサC2（1μF・400V）の電荷をイグニッションコイル1次側へ一瞬で全放電する。
* **物理制限**: 車体サイドカバー内収納のため、基板最大サイズは **28.5mm × 80.0mm**。
* **クランクセンサー位置**: **BTDC 27.0°（固定）**。1回転に1回パルスが発生する **「捨て火（Wasted Spark）方式」**。パルサー信号はフォトカプラを介してマイコン（ESP32-S3 / Arduino Nano）へ **FALLING（立ち下がり）パルス** として入力。

---

## 2. 開発の歴史と重要なバグフィックス（Debug History）

オシロスコープとデジタルパルスシミュレーターを用いた過酷なベンチテストにより、以下の致命的バグを解決し、堅牢な点火ロジックを確立済みです。

### 【フェーズ1：基礎ロジックと演算制約の突破】

1. **ISR内FPUクラッシュバグ**: ESP32-S3の外部割り込み（ISR）内で `float` 計算を行うとクラッシュするため、すべての計算を32ビット整数（角度は10倍の固定小数点、例：17.0°➔`170`）へ完全移行。
2. **タイマー上書きデッドロック（加速時パルス消失）**: ISR内でタイマーの停止・再始動を行うと、加速時に次のパルスが早く入りすぎてタイマーが上書き・消滅。対策として、タイマーを止めずにカウント値の0リセットとアラーム値の更新のみを行う **「ノン・ストップ型高速リフレッシュ駆動」** を確立。
3. **過渡期予測の遅れによる「逆飛びジャンプ」**: 加減速時にパルスが大きく飛び跳ねる現象に対し、「最新の生の1回転周期（`intervaltime`）」のみから進角前借り分を引き算する **「時間軸反転・等倍相殺ディレイ演算」** へ一本化。
4. **端数丸め誤差による定常時ブレ**: 分子を16ビット左シフトさせてから演算する **「高分解能固定小数点直線補間論理」** を導入。
5. **反転論理によるR3（1kΩ）の異常発熱**: 回路上の正常発熱と判断。点火ロジックを「通常High・点火時一瞬Low」に固定し、ハードウェア側で許容損失の大きい抵抗器を配置して放熱解決。

### 【フェーズ2：デジタルシミュレーションによる過渡特性の完全制覇】

6. **急加速時の予測突破と失火**: 予測より早く物理パルスが到達した際、タイマーが間に合わず失火・不安定化する問題が発生。対策として、ISR発火時にタイマー未発火であれば即座にベースタイミングで点火を強制する **「フェイルセーフ・レスキュー点火（Rescue Spark）」** を実装。
7. **微小進角領域（3500〜4500rpm）のジッター**: センサー由来の数μsのハードウェアノイズが予測周期を揺さぶり、点火タイミングが激しくブレる問題が発生。FPUを使わずに定常状態を推定する **「32ビット整数型 $\alpha-\beta$ フィルタ」** を導入。マイコン内部に仮想フライホイールを構築し、外乱ノイズを完全に相殺することで、オシロスコープ上でピタリと静止する極めて安定した点火パルス生成に成功。

### 【フェーズ3：リアルタイム性の極限追及とマルチタスク化】

8. **FreeRTOSによるデュアルコア完全分離**: シリアル通信（`Serial.print`）による微小なブロッキングリスクを排除するため、ESP32-S3のデュアルコアを活用。Core 1を「点火制御専用タスク」として100%割り当て、Core 0に「UI/通信/RPM平滑化」のバックグラウンドタスクをピン留め。これにより、通信負荷が点火タイミングに一切影響を与えない完全なリアルタイム駆動を実現。
9. **$\alpha-\beta$ フィルタ係数の最適化と定数化**: 実際の加減速時のパルスシフト量のスムーズさを向上させるため、オシロスコープ検証を経てフィルタ係数を $\alpha=1/2$, $\beta=1/8$ へチューニング。さらに将来の調整を容易にするため、ビットシフト量をマクロ（`#define AB_FILTER_ALPHA_SHIFT 1`等）として一括管理化。

---

## 3. 最終制御ソフトウェア（ESP32-S3版）

最新のソースコードは、「整数型 $\alpha-\beta$ フィルタ（最適化済み）」「レスキュー点火」「デュアルコア（FreeRTOS）分離アーキテクチャ」を搭載し、等時性・追従性・安全性を極限まで高めたバージョンです。実車テストへの投入準備が完了しています。

## 4. 次ステップ：KiCad物理基板設計での注意申し送り（PCB Layout Rule）

基板サイズ **28.5mm × 80.0mm** 内へのレイアウトにおいて、以下のノイズ防御策を厳守してください。

1. **「強電（AC-CDI）」と「弱電（マイコン）」のエリア物理隔離**:
   基板の左側を「マイコン・LDO電源エリア」、右側を「サイリスタ・C2・高圧入力エリア」として完全分割。その境界線上にフォトカプラ（U2）を配置し、高圧ノイズの回り込みを遮断する。
2. **ベタGNDの分離とR5（0Ω抵抗）による一点グランド結合**:
   「マイコン共通GNDゾーン」と「車体アースGNDAゾーン」を基板上でスリットを入れて完全に分離。両者は **3.3Vレギュレータ（U1）のGNDピン直下の1点のみ** で、R5（0Ω抵抗）を介して結合する。
3. **太い配線パターンの確保と放熱抵抗配置**:
   サイリスタ放電ライン、C2周辺のパターンは **1.5mm〜2.5mm幅の極太** で配線。常時発熱するR3（1kΩ）の周辺銅箔は放熱用に広く確保する。
